# Дикий дрифт · Лазурный серпантин

Локальная 3D-гонка с оригинальными зверятами. Новая трасса: **1,887 км**, высоты **7–65 м**, два разрыва разводных мостов **22 и 26 м**, три круга и пять соперников.

## Играть в браузере

[Открыть Дикий дрифт](https://phoenixtur.github.io/wild-drift/) — скачивать игру не нужно.

## Запуск на Mac

На GitHub нажми **Code → Download ZIP**, распакуй архив и открой `Дикий дрифт.html`.

Открой `Дикий дрифт.html` в Safari или Chrome. Все ресурсы встроены: этот файл можно переносить отдельно, установка, сервер и интернет не нужны. `Играть.command` открывает его в Safari.

Исходная версия `index.html` требует остальные файлы папки рядом. Это браузерная игра, не приложение `.app`. Нужен WebGL с аппаратным ускорением.

## Управление

- **W / ↑** — газ. **S / ↓** — тормоз.
- **A / ← и D / →** — руль. Карт движется свободно в пространстве и не поворачивает вслед за трассой. Отпусти руль — он продолжит движение по своему направлению.
- **Пробел + руль** — занос. Сцепление падает, корпус поворачивается относительно направления движения; удерживай занос и корректируй его контррулём. Отпусти пробел после наполнения шкалы, чтобы получить турбо. Просто удерживать пробел на прямой бесполезно.
- **Shift** — использовать предмет из руки. Кокос летит вперёд, отскакивает от дороги и замедляет соперника при попадании. Ягодная бомба летит по дуге и замедляет соперников в радиусе взрыва. Турбо ускоряет, щит защищает 7 секунд. Соперники тоже могут использовать предметы.
- **R** — вернуться на середину дороги, если развернулся или застрял.
- **Esc** — пауза. При переключении окна гонка автоматически останавливается.
- Кнопки сверху — звук и полный экран. Звук изначально выключен. На сенсорном экране появляются кнопки управления.

## Трасса

Перед разрывами мостов есть предупреждения, разгонные полосы и наклонные секции. Держи скорость и выровняй карт перед отрывом: в полёте горизонтальная скорость сохраняется, довернуть траекторию нельзя. Недостаточный разгон приводит к падению.

С края дороги можно вылететь. После короткой анимации падения карт появляется в центре дороги возле места вылета, со скоростью 2 м/с и временной защитой. При недолёте до второго края моста возвращение происходит перед трамплином, с запасом места для повторного разгона. Время гонки при этом идёт.

Фокси быстрее реагирует на руль, Рокки дольше ускоряется, Бонни имеет более высокую максимальную скорость. Рекорды новой трассы сохраняются отдельно от прежней короткой трассы, если браузер разрешает локальное хранилище.

## Разработка и проверки

- `node check.cjs` — проверяет свободное управление без автоповорота, инерционный занос, ускорение, оба прыжка и недолёт, возврат на дорогу, броски и попадания, щит, три круга с тестовым водителем и переходы интерфейса. Также создаёт реальную 3D-сцену с подменённым GPU: проверяет геометрию разрывов, предмет в руке, полёт предмета и анимацию появления.
- `node build.cjs` — пересобирает автономный `Дикий дрифт.html` после изменений исходников.

Эти проверки не проверяют картинку, ощущения от клавиатуры и FPS на конкретном Mac. В игровом режиме автоматический водитель управляет только соперниками; тестовый водитель для проверки полного заезда недоступен игроку.

Физика — аркадная: независимые координаты, курс и скорость, боковое сцепление, вертикальное движение под действием гравитации. Это не инженерный симулятор подвески.

Three.js 0.160.1 хранится локально; MIT-лицензия — `vendor/THREE-LICENSE.txt`. Обложка создана для игры, персонажи и оформление оригинальные. Звук синтезируется через Web Audio. Внешних запросов при запуске нет.
